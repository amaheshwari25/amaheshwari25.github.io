# amaheshwari.com

The source for Arya Maheshwari's academic website. It is a small custom Jekyll
site designed for GitHub Pages.

## Preview locally

```sh
bundle install
bundle exec jekyll serve
```

Open <http://127.0.0.1:4000>.

The homepage copy lives in `index.html`. Navigation and publication data live
in `_data/navigation.yml` and `_data/publications.yml`.
